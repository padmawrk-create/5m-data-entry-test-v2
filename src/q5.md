# Question 5 — Operating Systems, Terminals, and Shells

**Format:** Short Answer

---

> Answer in your own words, 1-3 sentences each. Writing it yourself is the point.


**(a)** What is a **kernel**, in plain language? (One or two sentences. No textbook definition copied in; explain it as you understand it.)

**Answer:**
a kernel is the part of the operating system that connects the software with the computer's hardware. It manages things like memory, the CPU, and devices so everything works properly.

---

**(b)** A classmate says:

> "I installed WSL, so now I have two completely separate operating systems, Windows and Linux, running side by side, each totally independent."

Is this accurate? Briefly explain why or why not.

**Answer:**
I don't think that's completely true. WSL lets me use a Linux environment on my Windows computer, but it still depends on Windows, so they are not two completely separate operating systems running independently.

---

**(c)** Explain the difference between a **terminal (emulator)** and a **shell**, and give one example of each.

**Answer:**
I think of a terminal as the window where I type commands, and the shell as the program that understands and runs those commands. For example, Windows Terminal is a terminal, and PowerShell is a shell.
